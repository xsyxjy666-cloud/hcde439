      void setup() {
        // Set all six LED pins as outputs
        pinMode(LED1, OUTPUT);
        pinMode(LED2, OUTPUT);
        pinMode(LED3, OUTPUT);
        pinMode(LED4, OUTPUT);
        pinMode(LED5, OUTPUT);
        pinMode(LED6, OUTPUT);
      }

      void loop() {
        // Pattern 1: Alternating (LED1,3,5 on / LED2,4,6 off)
        digitalWrite(LED1, HIGH);   // Turn on LED1
        digitalWrite(LED3, HIGH);   // Turn on LED3
        digitalWrite(LED5, HIGH);   // Turn on LED5
        digitalWrite(LED2, LOW);    // Turn off LED2
        digitalWrite(LED4, LOW);    // Turn off LED4
        digitalWrite(LED6, LOW);    // Turn off LED6
        delay(400);                 // Wait 400 ms

        // Switch: LED2,4,6 on / LED1,3,5 off
        digitalWrite(LED1, LOW);    // Turn off LED1
        digitalWrite(LED3, LOW);    // Turn off LED3
        digitalWrite(LED5, LOW);    // Turn off LED5
        digitalWrite(LED2, HIGH);   // Turn on LED2
        digitalWrite(LED4, HIGH);   // Turn on LED4
        digitalWrite(LED6, HIGH);   // Turn on LED6
        delay(400);                 // Wait 400 ms

        // Repeat pattern 1 (same as above)
        digitalWrite(LED1, HIGH);
        digitalWrite(LED3, HIGH);
        digitalWrite(LED5, HIGH);
        digitalWrite(LED2, LOW);
        digitalWrite(LED4, LOW);
        digitalWrite(LED6, LOW);
        delay(400);

        digitalWrite(LED1, LOW);
        digitalWrite(LED3, LOW);
        digitalWrite(LED5, LOW);

        digitalWrite(LED4, HIGH);
        digitalWrite(LED6, HIGH);
        delay(400);

        // Turn off all LEDs before next pattern
        digitalWrite(LED2, LOW);
        digitalWrite(LED4, LOW);
        digitalWrite(LED6, LOW);
        
        // Pattern 2: Loop clockwise 1 by 1

Additional Questions

Q1: Voltage Drop of the LEDs Over Time

The graphs show the voltage across LEDs 1~3 and LEDs 4~6 over time.


Q2: How many LEDs could you blink independently with your Arduino? How much current would that draw?

The ATmega328P datasheet lists a 200mA absolute maximum for total current and a 40mA maximum per pin. However, the recommended maximum total current is 150mA, and the current per pin is 20mA. 150mA ÷ 20mA = 7.5, so about 7 LEDs can be blinked independently and draw about 140mA in total.


Q3: How fast do you need to blink your LEDs until you no longer can tell that they are blinking?

I tested different delay values:

  • 10ms — clearly blinking
  • 9~8ms — faint / borderline
  • 7ms — cannot tell, looks steady

My threshold is around 8.5ms delay, which means about 58.8 blinks per second.
